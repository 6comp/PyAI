UI overview

The main window is split into two columns:

  • Config bar (left): "About / Help / Settings / Character Setup" entries;
  • Chat area (right): action buttons on top (head pat / hug / save dialog), the conversation view in the middle, and the input field with a "Send" button at the bottom.

Data & privacy

All data is stored locally and is not shared with any third party other than the program author (conversation content is sent to the DeepSeek API on demand to generate replies).

  • API Key: encrypted with AES-256-GCM; the key lives in the system keyring, the ciphertext in data/settings.db;
  • Data files: data/dialogs.db (chat history & memories), data/system.db (runtime/system settings), data/settings.db (user settings & key info);
  • Logs: stored in the log/ directory for troubleshooting.

FAQ

Q: "You haven't configured the API" on launch?Open "Settings", fill in the API-KEY and save. See "About the API-KEY".
Q: "You haven't configured a companion" on launch?Complete "Character Setup" (name, gender, etc.). See "About Character Setup".
Q: "Request failed" after sending?Check that the API-KEY is valid, the network is reachable and your account has balance; inspect the logs under log/.
Q: "No new dialogs yet" when saving?There is no unsaved conversation — chat first, then save.
Q: "You haven't configured a companion" when saving?Finish "Character Setup" before using the save feature.
Q: "Some required files are missing" on launch?Make sure the program directory is complete (config.json, analysis_config, img/, docs/HelpIndex.html, etc.) or re-extract/reinstall.

Logs & troubleshooting

You can adjust the log level via a command-line argument:

python pyai.py -l DEBUG

Available levels: DEBUG (most verbose), INFO (default), WARNING, ERROR. Logs are named by module (e.g. api.log, ui.log) under the log/ directory.
