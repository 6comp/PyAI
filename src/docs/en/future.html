Future Updates

Features that are currently planned or under development.

Day / Night mode planned

A "day / night" toggle already exists in "Settings", but the dark UI theme is not implemented yet and will be completed in a future release.

Voice reading in development

PyAI already includes EdgeTTS text-to-speech (voice.py) which can download and cache AI replies. The reading toggle has not been exposed in the UI yet, and will let the AI "speak" in the future.

More plans

  • More voices and broader language support;
  • Improved search and management of chat history;
  • Better memory analysis and character profiling.

Release dates are subject to the project repository. Stay tuned.
