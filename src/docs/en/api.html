About the API-KEY

The API-KEY is the access credential required for PyAI to call the DeepSeek model.

What is the API-KEY

PyAI does not ship with any built-in model. Instead, it generates replies by calling DeepSeek's public API. The API-KEY is your access credential, usually in the form of sk-xxxxxxxx.

How to obtain one

  1. Sign up and log in at the DeepSeek platform: platform.deepseek.com;
  2. Open the "API Keys" page in the console and click "Create API Key";
  3. Name the key, create it, then copy it (store it safely, as it may not be shown again).

Configure it in PyAI

  1. Open PyAI and click "Settings" on the left;
  2. Paste the API-KEY into the API field;
  3. Click "Back" at the top-left, then confirm to save.

Security

PyAI encrypts your API-KEY with AES-256-GCM. The encryption key is stored in the system keyring, while the ciphertext and tag are stored in the local data/settings.db. It is never written to disk in plain text.

Tip: If you see "Request failed" when sending a message, first check whether the API-KEY is valid, whether your account is available, and whether your network is reachable.
