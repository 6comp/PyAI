关于其他

界面说明、快捷键、数据隐私与常见问题解答。

界面总览

主界面分为左右两栏：

  • 配置栏（左侧）：包含「关于 / 帮助 / 设置 / 伴侣配置」四个入口；
  • 对话区（右侧）：上方是动作按钮（摸摸头 / 抱一抱 / 保存对话），中间是聊天记录，下方是消息输入框与「发送」按钮。

快捷键

快捷键功能
Enter发送消息
Ctrl + S保存对话（触发记忆分析）

数据与隐私

程序所有数据均保存在本地，不会上传给程序作者以外的第三方（对话内容会按需发送至 DeepSeek API 用于生成回复）。

  • API Key：使用 AES-256-GCM 加密，密钥存于系统钥匙串，密文存于 data/settings.db；
  • 数据文件：data/dialogs.db（聊天记录与记忆）、data/system.db（运行时/系统设置）、data/settings.db（用户设置与密钥信息）；
  • 日志：保存在 log/ 目录，便于排查问题。

常见问题（FAQ）

Q：启动提示「您还未配置 API」？进入「设置」填入 API-KEY 并保存，详见「关于 API-KEY」。
Q：启动提示「您还未配置伴侣」？进入「伴侣配置」完成名字、性别等设置，详见「关于人物配置」。
Q：发送消息后提示「请求时发生错误」？请检查 API-KEY 是否有效、网络是否通畅、账户是否有余额，并查看 log/ 下日志定位原因。
Q：保存对话提示「还没有新的对话记录」？当前没有未保存的新对话，先聊天再保存即可。
Q：保存对话提示「你还没有配置过伴侣」？先完成「伴侣配置」再使用保存功能。
Q：启动提示「有所需文件缺失」？请确认程序目录完整（config.json、analysis_config、img/、docs/HelpIndex.html 等），或重新解压安装。

日志与排查

程序支持通过命令行参数调整日志级别：

python pyai.py -l DEBUG

可选级别：DEBUG（最详细）、INFO（默认）、WARNING、ERROR。日志按模块命名（如 api.log、ui.log 等），保存于 log/ 目录。
