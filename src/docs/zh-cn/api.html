关于 API-KEY

API-KEY 是 PyAI 调用 DeepSeek 模型所必需的访问凭证。

什么是 API-KEY

PyAI 本身并不内置任何大模型，而是通过调用 DeepSeek 开放的 API 接口来生成回复。API-KEY 就是你的访问凭证，通常形如 sk-xxxxxxxx。

如何获取

  1. 前往 DeepSeek 开放平台：platform.deepseek.com 注册并登录；
  2. 在控制台「API Keys」页面点击「创建 API Key」；
  3. 为密钥命名并创建，复制生成的 Key（请妥善保管，页面关闭后可能无法再次查看）。

在 PyAI 中配置

  1. 打开 PyAI，点击左侧的 「设置」；
  2. 将 API-KEY 粘贴到 API 输入框；
  3. 点击左上角 「返回」，在弹出的确认框中点击「确定」以保存。

安全说明

PyAI 会对你的 API-KEY 进行加密保护：使用 AES-256-GCM 算法加密，加密密钥保存在系统钥匙串（keyring）中，密文与校验码则存入本地 data/settings.db，全程不会以明文形式落盘。

提示：若发送消息时提示「请求时发生错误」，请优先检查 API-KEY 是否正确、账户是否可用以及网络是否畅通。
