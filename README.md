### 环境配置
**Python version >= 3.12**


- #### 工具升级，保证安装时不会出现一般问题 
```shell 
python -m pip install --upgrade pip wheel setuptools
```

<br>

- #### 安装环境
```shell
pip install -e .
```
或者
```shell
pip install -r requirements.txt
```

<br>

**注意：记得转到项目目录下**
